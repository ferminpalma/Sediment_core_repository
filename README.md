# Sediment_core_repository
Interactive QGIS project with the location and data of sediment cores (box corer and gravity corer) collected along the Argentine Continental Margin, 2017-2023.

## Requirements
QGIS 3.x

## How to use
1. Download the repository .csv file and the QGIS project.
2. Open the `.qgz` project file in QGIS.
3. Activate the *Run Feature Action* tool and click on a core.

## Data sources
- Bathymetry: GEBCO 2026 (download from https://download.gebco.net/) 
- Boundaries: National Geographic Institute of Argentina (IGN) https://www.ign.gob.ar/NuestrasActividades/InformacionGeoespacial/CapasSIG
